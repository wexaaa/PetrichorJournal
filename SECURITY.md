# Security and privacy

Petrichor Journal is designed as an offline, client-side recorder. It does not send reports, telemetry, player names, or configuration data over the network.

Reports are stored under `BepInEx/config/PetrichorJournal/archive`. Multiplayer names are redacted by default, but reports may still reveal survivor choices, timestamps, mod lists, and notes. Review a report before sharing it publicly.

For a security or privacy issue, open a GitHub issue without attaching sensitive reports or logs. Describe the affected version and provide a minimal reproduction. Sensitive proof should not be posted publicly.
