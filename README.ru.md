# Petrichor Journal

**Petrichor Journal** — локальный журнал забегов для Risk of Rain 2. Он сохраняет историю этапов, развитие билда, изменения предметов, причину смерти, финальную статистику и список загруженных модов. Аккаунт, сервер и отправка телеметрии не требуются.

Текущая версия: **0.1.3 beta**. [English README](README.md).

![Подробности забега](docs/screenshots/run-details.png)

## Возможности

- отдельный JSON-отчёт для каждого забега;
- атомарное автосохранение и сохранение оборванных забегов;
- история этапов со временем входа и выхода;
- снимок характеристик персонажа и полного билда на каждом этапе;
- таймлайн получения и потери предметов локального игрока;
- финальная статистика всех участников из `RunReport`;
- финальные предметы и экипировка игроков;
- убийца, величина последнего урона и его флаги;
- названия, GUID и версии всех загруженных BepInEx-плагинов;
- поиск по персонажу, этапу, предмету, результату, заметкам и модам;
- фильтры побед и поражений, заметки и копирование текстовой сводки;
- скрытие имён участников в виде `Player 1`, `Player 2` по умолчанию.

## Приватность

Мод не содержит сетевого или телеметрического кода. Он не изменяет профиль, достижения, баланс, RNG, сохранения или встроенную историю RoR2. Все файлы создаются только в собственной папке:

```text
BepInEx/config/PetrichorJournal/archive
```

## Установка

Через r2modman или Thunderstore Mod Manager:

1. Скачайте `PetrichorJournal_0.1.3.zip` из GitHub Releases.
2. Откройте **Settings → Import local mod**.
3. Выберите ZIP и запустите модифицированную игру.

Ручная установка: поместите `PetrichorJournal.dll` в `BepInEx/plugins/PetrichorJournal/`.

## Использование

- **F8** — открыть или закрыть журнал.
- **Escape** — закрыть окно.
- Список забегов находится слева, подробности выбранного забега — справа.
- Клавиша и параметры записи настраиваются в `BepInEx/config/com.petrichorjournal.core.cfg`.

## Ограничения beta-версии

- Интерфейс пока построен на IMGUI, а не встроен в Logbook.
- Таймлайн предметов записывается для локального игрока; финальная статистика включает всех участников отчёта игры.
- Для смерти сохраняется последний удар, а не полная история полученного урона.
- В старых отчётах версий 0.1.0–0.1.2 могли сохраниться только основные поля. Утраченные тогда данные восстановить невозможно.
- Полная русская локализация элементов интерфейса и управление контроллером пока не реализованы.

## Сборка

```powershell
dotnet restore src/PetrichorJournal/PetrichorJournal.csproj
dotnet build src/PetrichorJournal/PetrichorJournal.csproj -c Release --no-restore
```

Готовая DLL появляется в `src/PetrichorJournal/bin/Release/netstandard2.1/`.
